## 작업 목표

- 멀티 뷰/배속 환경에서 애니메이션/공정 진행 동기화를 개선
- `USD_TIMELINE` 배속 적용 및 스텝 간 “완료 후 다음 시작” 보장
- 진행현황에 공정시간/애니시간을 동시에 노출하고, 공정시간우선 정책을 명확화
- EP 포트 점유 상태(EP1/EP2/ALL_EP) 타임라인 막대 그래프 추가 + 종료 요약 로그에 idle 통계 추가
- stop/reset 이후 간헐적으로 애니가 안 도는 문제(잔여 상태) 정리
- 시뮬 “사전 샘플링(시작 시 난수 고정/미리 계산)” 설계로 변경

---

## 변경 요약(핵심)

- **배속 정책 통일**
  - `MOVE/ROTATE/DELAY` duration 및 `step_delay_ms`를 배속으로 스케일
  - `USD_TIMELINE`은 time scale API가 없을 때 `current_time` 가속 폴백 추가
  - 그룹 스케줄은 “추정 duration”이 아니라 **앵커 스텝의 on_completed** 기반으로 다음 스텝 시작

- **진행현황 정책**
  - 진행현황에 `공정시간(proc_sec)`/`애니시간(anim_sec)`을 같이 표시
  - `공정시간우선 ON` + `공정 < 애니`일 때 100% 시점에 애니를 즉시 stop+초기화

- **EP 타임라인 그래프**
  - 처음엔 진행현황 패널 내부에 삽입 → 디듀프/클리핑/대기 구간 업데이트로 불안정
  - 최종: **포트상태 아래 전용 고정 영역**으로 분리(EP1/EP2(/EP3)/ALL_EP + 시간 라벨)
  - 시뮬 종료 요약 로그에 `EPn_EMPTY`, `ALL_EP_EMPTY` 누적(초) 출력

- **stop/reset 회귀 방지**
  - 화면별 runner/pending/active/pause/interrupt 등 잔여 상태를 stop/reset 시 완전 정리
  - reset 시 EP 타임라인 상태/위젯도 함께 초기화

- **사전 샘플링(시뮬 시작 시 미리 계산)**
  - spawn/pickup/이동 시간 난수 풀을 시작 시 생성, 런타임은 풀에서 순차 소비
  - `sim_total_est_sec`도 평균치가 아니라 “사전 샘플 합”으로 산출(이번 실행 기준 고정)

## 문제/증상과 해결(메모)

### 1) 진행현황에 막대 그래프가 안 보이거나 ALL_EP만 보임

- **원인**
  - 진행현황 텍스트 디듀프가 그래프 갱신까지 막음
  - 스크롤/레이아웃/클리핑으로 EP1/EP2/라벨이 잘리고 마지막 줄만 보이는 케이스 빈발
  - 대기 구간에는 progress emit이 없어서 그래프가 멈춤

- **해결**
  - 진행현황과 그래프를 분리(포트상태 아래 전용 영역)
  - 포트 점유 스냅샷(ports_occupancy)을 기준으로 sim_time Δt를 누적
  - 대기 구간은 `timeline_only` progress를 주기 emit하고 “마지막 점유 스냅샷”으로 그래프만 전진

### 2) stop/reset 후 간헐적으로 애니가 재생되지 않음

- **원인**
  - 화면별 runner/큐/pause/interrupt 등 잔여 상태가 다음 실행을 방해

- **해결**
  - stop/reset 시 화면별 state(dict) 전체 초기화 + 이벤트 clear + 위젯 destroy

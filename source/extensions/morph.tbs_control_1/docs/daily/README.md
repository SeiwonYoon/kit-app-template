## 날짜별 작업 로그 규칙

이 폴더에는 **하루 단위로 작업 내용/시행착오/결론**을 기록합니다.

### 파일명

- `YYYY-MM-DD.md`
  - 예: `2026-04-14.md`

### 권장 포맷

- **작업 목표**
- **변경 요약(핵심 파일/핵심 로직)**
- **문제/증상**
- **원인 분석**
- **시도했던 해결(실패 포함)**
- **최종 해결**
- **남은 TODO / 다음 작업**

### 작성 원칙

- “무엇을” 보다 **“왜 이렇게 했는지/왜 안 됐는지”**를 우선 기록
- UI/엔진처럼 얽힌 이슈는 **재현 조건**과 **회귀 포인트**를 꼭 남기기

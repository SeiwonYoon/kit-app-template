## 작업 목표

- EP 타임라인 막대그래프 우측의 “누적 EMPTY 시간(초)”이 종료 요약 로그에도 반영되는지 확인
- 확장 로드 실패(IndentationError)로 UI 창(제어창/시퀀스 편집창) 사라지는 문제 복구
- 위 두 내용을 코드에서 바로 추적 가능하도록 주석 보강

---

## 문제/증상

### 1) 확장 로드 실패로 UI 창이 사라짐

- 로그:
  - `IndentationError: unindent does not match any outer indentation level`
  - 위치: `control_window.py` line 2871 근처
- 결과: `morph.tbs_control_1` 확장 로드가 실패하면서 TBS 제어창/시퀀스 편집창이 뜨지 않음

### 2) EP/ALL_EP 누적 EMPTY 시간이 “요약 로그에도 찍히는지” 확인 필요

- UI에 표시되는 값(막대 우측 숫자)이 종료 시점 요약(`[SUMMARY]`)에도 포함되는지 코드 기준으로 검증 필요

---

## 원인 분석

### 1) IndentationError

- `_update_ep_timeline_under_port_state()` 내부에서 `for r in rows:` 블록과 “우측 누적 EMPTY 라벨” 블록의 들여쓰기 레벨이 깨져,
  파이썬 파서가 import 단계에서 `IndentationError`를 발생시킴.

### 2) “우측 누적” vs “요약 로그”의 데이터 원천

- UI 우측 숫자:
  - `control_window.py`의 그래프 상태(`rows_state` 세그먼트 dur 누적)를 합산해 `empty_acc`로 표시
- 종료 요약 로그:
  - `simulation_engine.py`에서 tick 기반으로 `_ep_empty_sec`, `_all_ep_empty_sec`를 누적한 뒤,
    `_log_final_summary()`에서 `{EP}_EMPTY`, `ALL_EP_EMPTY`를 출력

두 값은 구현상 원천이 다르지만, **의미/정의(EMPTY 누적 시간)**는 동일하도록 설계됨.

## 최종 해결

### 1) 들여쓰기 복구로 확장 로드 정상화

- 파일: `morph/tbs_control_1/control_window.py`
- 조치:
  - `_update_ep_timeline_under_port_state()`의 막대 렌더 루프와 우측 누적 라벨 구간을
    `with ui.VStack(...)` 내부로 정상 정렬하여 파서 오류 제거

### 2) “EP/ALL_EP 누적 EMPTY 시간”의 흐름이 코드에서 바로 보이도록 주석 보강

- 파일: `morph/tbs_control_1/simulation_engine.py`
  - `_ep_empty_sec`, `_all_ep_empty_sec`가
    - 어디서 누적되는지: `_accumulate_sim_stats()`
    - 어디서 요약 출력되는지: `_log_final_summary()`
    를 주석으로 연결
- 파일: `morph/tbs_control_1/control_window.py`
  - `empty_acc`가 “UI 표시용 합산값”임을 명시하고,
    요약 로그는 `simulation_engine.py`의 누적값을 사용한다는 연결 주석 추가

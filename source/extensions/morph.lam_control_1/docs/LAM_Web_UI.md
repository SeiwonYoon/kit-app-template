# LAM 웹 원격 UI

HTTP 브리지·웹 패널·React 스트리밍 UI는 **`morph.lam_web_bridge`** 확장으로 분리되었습니다.

- 상세 가이드: `source/extensions/morph.lam_web_bridge/docs/LAM_Web_UI_Guide.md`
- Kit 앱에서 원격 UI를 쓰려면 `morph.lam_web_bridge` 확장을 로드하세요 (`morph.editor.kit`에 포함됨).

`morph.lam_control` 만 로드하면 LAM Window·CSV Play 등 **Kit UI 기능**은 그대로이고, **브라우저 8720 패널**은 뜨지 않습니다.

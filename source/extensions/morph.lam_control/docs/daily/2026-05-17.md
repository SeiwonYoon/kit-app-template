### 1.2 수정 (`lam_composition_discovery.py`, `lam_window.py`)

| 항목 | 내용 |
|------|------|
| Discover | R1: `lam:instance` customData (save/load 형식 tolerant). R2/R3: **`/World` 직계 자식만** |
| Open Master | registry 정리 → discover → **모든 인스턴스 Extract 자동** (`_auto_extract_after_master_open`) |
| 수동 Discover 버튼 | Extract 자동 **없음** (기존과 동일) |

### 1.3 자동 로드 (`lam_window.py` import 직하)

```python
load_automatically = False   # True / False (Python 대문자)
default_load_usd_path = "lam/usd/master.usd"  # 절대 또는 프로젝트 루트 상대
```

- `resolve_default_load_usd_path()` — 상대 경로는 `lam/` 부모 = 프로젝트 루트 기준.
- 첫 `show()` 시 `post_update` **3프레임 지연** 후 `_open_master_at_path()` (omni.anim.window.timeline `AttributeError` 완화).
- 오류: `load_automatically = true` → `NameError` → **`True`** 로 수정 안내.

## 3. ATM / VTM 슬롯 Z SSOT (`lam_slot_z_config.py`)

### 3.1 배경 (`prompt1.txt` 44~161)

- 장비 문서 Z(mm): ATM 기준 905.92, FOUP/Buffer/Cooling/Aligner/Airlock 등.
- VTM 기준 959.99, chamber1~4 = 978.81, chamber5(stripper) = 956.482, airlock 동일 패턴.
- **로봇팔(EE) Z 는 테이블에 포함하지 않음.**

### 3.2 파일 구조

```
ATM_Z_DOCUMENT_REFERENCE = 905.92    # prompt 원문 (고정)
ATM_Z_APPLIED_REFERENCE  = 905.92    # 변경 시 전체 effective Z 이동

ATM_SLOT_Z_ABSOLUTE  { "foup1_1": 931.848, ... }   # 수동 [mm]
ATM_SLOT_Z_DELTA     { "foup1_1": 25.928, ... }   # 자동: 절대 − APPLIED

VTM_Z_DOCUMENT_REFERENCE / VTM_Z_APPLIED_REFERENCE
VTM_SLOT_Z_ABSOLUTE / VTM_SLOT_Z_DELTA
```

| 용도 | 공식 [mm] |
|------|-----------|
| 표시용 DELTA | `절대Z − APPLIED_REFERENCE` (예: 931.848 − 905.92) |
| 시뮬 effective | `절대Z − DOCUMENT_REFERENCE + APPLIED_REFERENCE` |
| 시뮬 [m] | `load_atm_z_tables()` → `(baseline_m, delta_dict)` — `Z_MM_TO_METERS = 0.001` |

**검증:** `APPLIED_REFERENCE` 905.92 → 900.92 시 `foup1_1` effective **−5 mm**.

### 3.3 `simulation_play.py` 연동

- `default_lam_sim_virtual_config()` — `load_atm_z_tables()` / `load_vtm_z_tables()` 로 `z_slot_delta_m`, `vtm_z_slot_delta_m` 채움.
- 기존 `_z_slot_delta` placeholder / `zd(0.091)` 샘플 **제거**.

### 3.4 절대 Z MOVE (기존)

- 시퀀스 JSON 의 **절대 좌표 MOVE** (`move_from_initial`) — 슬롯 Z = `effective_slot_z_m(slot_key)`.
- 델타만 저장해도 런타임은 baseline + delta 로 절대 높이 산출.

## 4. 시퀀스 에디터 PRIM_VISIBILITY (Hide / Show) — 구현 완료

**목적:** ATM **in** 클립(프레임 재생) 전후로 **웨이퍼 prim** 을 슬롯/팔에 맞게 보이기·숨기기.

| UI | 동작 (합의 이해) |
|----|------------------|
| 드롭다운 **hide** + prim 경로 | 해당 스텝 **이후** 그 prim 을 **강제 숨김** (다른 동작 없음). 이후 스텝까지 유지 |
| 드롭다운 **show** + prim 경로 | 그 순간부터 **무조건 표시** (현재 visibility 상태 무관) |
| **스텝당 prim 1개** | 한 Hide/Show 스텝 = 경로 **한 줄**만. 여러 prim 은 스텝을 나눠 나열 |
| 워크플로 | in 재생 → show(슬롯 웨이퍼) / hide(팔·기타 웨이퍼) 등을 시퀀스에 끼워 **유기적** 전환 |

**기존 코드와 구분:**

| 기존 | 차이 |
|------|------|
| `hide_enabled` + `hide_prims` (MOVE 등 스텝 부가) | 스텝 duration 동안만 임시 hide → 끝나면 unhide |
| `SET_PRIM_VISIBILITY` (`lam_sequence_engine.py` 에만 존재) | 에디터 `STEP_TYPES` 미포함. `visible` bool + duration. **sticky hide/show 아님** |

### 4.1 구현 요약

| 파일 | 내용 |
|------|------|
| `lam_sequence_editor.py` | `STEP_TYPES` 에 `PRIM_VISIBILITY` 추가. UI: 동작 ComboBox (`hide`/`show`) + PRIM 1개 + Stage(첫 선택만). `hide_enabled` 미표시 |
| `lam_sequence_engine.py` | `step_kind_is_prim_visibility()` / `prim_visibility_step_visible()`. main thread 에서 `MakeVisible`/`MakeInvisible` (sticky) |
| JSON 로드 | `SET_PRIM_VISIBILITY` / `PRIM_HIDE` / `PRIM_SHOW` → `PRIM_VISIBILITY` + `mode` 로 정규화 |

예시 JSON:

```json
{
  "type": "PRIM_VISIBILITY",
  "mode": "show",
  "prim": "/World/LAM_WaferPosition_v01/.../Wafer_01",
  "duration": 0.02,
  "run_with_previous": false,
  "step_delay_ms": 0
}
```

`simulation_play` 매크로의 `SET_PRIM_VISIBILITY` 스텝은 엔진에서 그대로 실행(호환).

# morph.lam_control

LAM 멀티 USD 독립 타임라인 재생 + LAM 시퀀스 편집기 + 외부 이벤트 러너 확장.

본 확장은 `morph.tbs_control_1` 와 **물리적으로 코드 격리** 되어 있으며, `omni.timeline` 도 사용하지 않습니다(`USD_Timeline_Spec.md` §3.1, REQ-002, REQ-004).
